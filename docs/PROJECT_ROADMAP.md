# ASSIS 90-Day Execution Roadmap

## Phase 1 Goal

Trained PPE detector (mAP50 ≥ 0.85) + working Streamlit demo + submitted
white paper — all publicly documented on GitHub.

| Task | Time | Done |
|---|---|---|
| Push repo to GitHub | 1 hr | ☐ |

| White paper Introduction drafted | 2 hr | ☐ |
